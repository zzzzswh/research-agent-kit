# 自动驾驶模式（Auto-Drive：单飞轮 + 多飞轮并行）

仅在用户明确说出开启口令（如“开启 auto-drive”“自动驾驶跑 #3”）时进入本模式；任务结束或触发熔断后**自动退出**并恢复普通权限。

---

## 1. 启动与预算锁定

进入前先确认（若用户未写全，采用下方默认保守值并在开跑前一行声明）：
- **目标范围**：对应的 `docs/TODO.md` 条目编号或明确探索方向。
- **单飞轮默认预算**：最多 **3 轮迭代**、单次实验 **≤ 15 分钟**、显式指定 `CUDA_VISIBLE_DEVICES`（未分配 GPU 时仅限 CPU 任务）。
- **并行模式（多飞轮）**：明确各飞轮的目标、独立分支名与各自独占的 GPU 编号（严禁两路共用同一张卡）。

---

## 2. 权限边界（临时放开 vs. 永久锁死）

### 临时放开（仅限隔离分支 / worktree 内）
- 方案与反方挑刺写入实验日志后直接执行，无需每轮停下等确认。
- 在预算内自主修改代码、运行 `uv run` 冒烟测试、诊断脚本与小规模验证实验。
- 每轮有效探索自动提交本地 commit（如 `auto(exp-a): round 1 - ...`）。

### 永久锁死（Auto-Drive 下依然严禁触碰）
- 严禁直接在 `main` / 主开发分支修改或提交代码。
- 严禁修改原始数据、冻结权重（`*_frozen_*.pt`）、测试集或已冻结的评测协议。
- 严禁直接改写 `docs/PROJECT.md` 故事线，严禁在并行期间修改共享的 `docs/TODO.md` 与 `docs/modules/*.md`。
- 严禁删除文件、升级正式组件版本号、打 tag 或 `git push`。

---

## 3. 环境隔离规则

### 单飞轮模式
从当前干净 HEAD 切出独立实验分支：
```bash
git checkout -b auto/<YYYYMMDD>-<任务简名>
```

### 多飞轮并行模式（防代码冲突、防抢卡、防文档撞车）
1. **目录与分支隔离（`git worktree`）**：为每个并行飞轮创建独立工作树与分支：
   ```bash
   git worktree add ../wt-<任务A> -b auto/<YYYYMMDD>-<任务A>
   git worktree add ../wt-<任务B> -b auto/<YYYYMMDD>-<任务B>
   ```
   若项目有大型数据目录或 `.venv`，在 worktree 内按需建立只读软链，避免重复拷贝。
2. **算力显式分片**：每个飞轮只能使用分配给自己的 `CUDA_VISIBLE_DEVICES`（或限定纯 CPU），严禁跨区占用。
3. **日志隔离**：每个飞轮只写自己分支下的 `runs/auto_<任务名>/journal.md`，不触碰共享的 `docs/` 正式文档。

---

## 4. 单轮执行循环（每轮必须留痕）

每轮迭代按以下 4 步推进，并追加写入 `runs/auto_<任务名>/journal.md`：
1. **写定本轮卡片**：记录本轮假设、反方挑刺（1~2 个可能失效点）、以及跑前锁定的通过/失败判据。
2. **实现与冒烟**：改代码并用假数据跑通单元测试/冒烟测试。
3. **运行预算内实验**：显式带 `CUDA_VISIBLE_DEVICES` 执行，记录耗时、关键指标（标明配置值 vs. 估计值）及产出图/HTML 路径。
4. **本地提交与决策**：无论正负结果均记录进 `journal.md`，有效改动打本地 commit；根据判据决定进入下一轮还是提前收敛。

---

## 5. 强制熔断条件（满足任一条立即停机汇报）

1. **预算耗尽**：达到最大迭代轮数或时间上限。
2. **停滞或卡死**：连续 2 轮无有效增益，或同一种报错连续 2 次未能定位修复。
3. **触及宏观决策**：发现需要修改 `docs/PROJECT.md` 故事线、改动评测协议、或需要超过预算的长训练任务。
4. **需要人眼拍板**：涉及视觉/样本质量判断时，自动生成离线 HTML 查看器并暂停，等待人工看图定夺。

---

## 6. 退出交付与收尾清理

停机后自动切回普通模式，向用户输出一份精简战报：
- **总结对比表**：每个分支 / 每轮试了什么、关键指标、离线查看器或图路径、对应 commit hash。
- **推荐动作**：明确建议保留哪一条分支/commit、丢弃哪几条，以及理由。

等用户拍板后再执行收尾：
- **采纳胜出方案**：合并对应分支后，走一次 `log-finding` 把定案结论归并进 `docs/modules/*.md` 与 `docs/TODO.md`。
- **清理隔离环境**（用户确认后执行）：
  ```bash
  git worktree remove ../wt-<任务名>
  git branch -D auto/<YYYYMMDD>-<未采纳任务>
  ```
